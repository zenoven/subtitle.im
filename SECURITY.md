# Security reports / 安全问题

Please report suspected vulnerabilities privately to [support@subtitle.im](mailto:support@subtitle.im), with the subject `subtitle.im security report`.

Include the affected product/version, reproduction steps and potential impact. Do not attach live passwords, verification codes, cookies, session tokens or payment credentials. Please avoid posting vulnerability details in public issues before we have had a chance to investigate.

发现疑似安全漏洞，请通过上述邮箱私下报告，标题使用 `subtitle.im security report`，说明受影响版本、复现步骤和可能影响。不要发送仍有效的密码、验证码、Cookie、会话令牌或支付凭据；在调查前请勿将漏洞细节公开到 Issue。
