# Reporting problems and sharing feedback / 问题与反馈

English and Chinese are welcome. / 欢迎使用中文或英文。

1. Check the [help page](https://subtitle.im/help/) and search [existing issues](https://github.com/zenoven/subtitle.im/issues).
2. Choose a form from [New issue](https://github.com/zenoven/subtitle.im/issues/new/choose).
3. Describe what you expected, what happened, and how to reproduce it. Add the extension and Chrome versions when relevant.
4. For subtitle detection, include a public video URL, timestamp, enabled caption track/language, burned-in subtitle language, and relevant settings. A cropped screenshot can help.

请先查看帮助并搜索已有问题，再选择表单。说明预期、实际结果及复现步骤；字幕问题请补充公开视频链接、时间点、当前软字幕轨及语言、硬字幕语言和相关设置。可附裁剪后的截图。

If the video is private, describe the issue and contact support rather than sharing an access link. Redact personal information from screenshots and logs. Do not post email verification codes, cookies, session tokens, account details or payment records in public issues.

私人视频不要公开访问链接。截图和日志请去掉私人信息；验证码、Cookie、会话令牌、账号与支付资料不要发到公开 Issue。

Account or payment help: [support@subtitle.im](mailto:support@subtitle.im). For security reports, see [SECURITY.md](SECURITY.md).

This repository accepts product reports and documentation suggestions. It does not include the extension's source or a public development roadmap. A feature request records an idea; it is not a delivery commitment.

本仓库接受产品问题、文档建议与使用反馈，不包含扩展源码或公开开发排期。收集建议不代表已承诺实现。
