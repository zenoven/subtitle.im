# subtitle.im

**YouTube 字幕，该开就开，该关就关。**

[官网](https://subtitle.im/zh-CN/) · [安装 Chrome 扩展](https://chromewebstore.google.com/detail/ehlfcnlpbeoncpoolmnocnjffmohhdbl) · [问题与反馈](https://github.com/zenoven/subtitle.im/issues/new/choose) · [English](README.md)

subtitle.im 是管理 YouTube 已有字幕的 Chrome 扩展：自动开启可用软字幕，在浏览器本地识别画面中的硬字幕，再按你的偏好处理重复字幕。软字幕可以随时恢复。

## 能做什么

- 自动开启 YouTube 已有的可用字幕。
- 视频自带硬字幕时，按偏好处理叠加的软字幕。
- 硬字幕与软字幕语言不同时，可选择自动关闭、先询问或保留。
- 从播放器恢复字幕；手动操作 CC 后，本次观看不再自动调整。
- Pro 提供频道规则、单个视频例外和已确认关闭结果的记忆。

免费体验无需注册，每次安装包含 10 个成功处理视频的额度。Pro 的当前方案以[官网](https://subtitle.im/zh-CN/#pricing)为准。

画面与字幕识别在浏览器本地进行，不向服务器上传视频帧或字幕文本用于检测；账号和购买服务会联网。

产品管理可开关的 YouTube 字幕，不生成、翻译、下载字幕，也不移除画面内的硬字幕。识别可能漏检或误判，误关时可以恢复。
